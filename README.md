# AdvancedDecorationTools

ADT 是一个面向《魔兽世界》住房系统的增强插件，核心目标是提升装修效率、放置精度与整体工作流体验。

目前项目主要通过 CurseForge 分发，已累计获得 14 万+ 下载。GitHub 仓库用于公开源码、问题跟踪与协作维护。

相关链接：

- CurseForge 发布页：https://www.curseforge.com/wow/addons/adt
- 源码仓库：https://github.com/RuofanYou/ADT

## 项目定位

原版住房编辑功能可以完成基础操作，但在重复放置、精确旋转、常用物品切换、颜色统一、批量装修与操作提示方面效率偏低。ADT 的目标不是替代原版编辑器，而是在不破坏原有操作习惯的前提下，把高频装修动作做得更快、更顺手、更可控。

## 核心功能

- 复制、剪切、粘贴、重复：支持常见快捷键工作流，减少反复翻目录与重新选择。
- 批量放置：按住组合键即可连续放置相同装饰，适合围栏、地砖、墙板等重复结构。
- 旋转增强：支持固定角度旋转、递增旋转与自定义步进，便于制作弧线、圆形与螺旋结构。
- 快捷栏：提供 8 个快速槽位，可直接绑定常用装饰并快速再次放置。
- 最近放置：自动记录最近使用的装饰，适合连续装修与反复微调。
- 临时收纳：在复杂调整过程中临时收起装饰，再快速取回继续摆放。
- 染色预设：保存常用配色方案，并快速复用到不同装饰上。
- 智能筛选：支持多标签组织方式，配合原版筛选更快定位目标物品。
- 悬停 HUD：显示装饰名称、库存与热键提示，减少来回确认成本。
- 现代化控制中心：提供 Dock/SubPanel 等界面组织方式，集中管理开关与配置。
- 多语言支持：以统一键集合维护本地化，覆盖全部客户端语言。

## 适用场景

- 大量重复摆放的地面、墙面、栅栏和路径铺设
- 需要等角度旋转的圆形、弧形、螺旋类造型
- 常用装饰频繁切换与库存确认
- 整屋家具配色统一与反复微调
- 长时间装修过程中的效率优化与误操作减少

## 安装

### 通过 CurseForge 安装

最简单的方式是直接通过 CurseForge 客户端或网页安装：

https://www.curseforge.com/wow/addons/adt

### 手动安装

1. 下载或克隆本仓库
2. 确保插件目录名为 `AdvancedDecorationTools`
3. 将目录放入《魔兽世界》正式服 AddOns 目录

macOS 常见路径：

```text
/Applications/World of Warcraft/_retail_/Interface/AddOns/AdvancedDecorationTools
```

## 使用

- `/adt`：打开或关闭设置面板
- 在住房编辑场景中使用复制、重复、批量放置、快捷栏、旋转增强等功能
- 具体热键可在 ADT 自带设置面板中查看与修改

## 兼容性

- 面向《魔兽世界》正式服住房系统
- 持续跟进 12.x 版本 API 变化
- 不依赖战斗自动化逻辑，聚焦住房编辑与界面增强
